# Серебрякова Александра 4-МД-15 — Audius Music Dashboard

## Тема

Музыкальная панель с виджетами на чистом JavaScript: список дел,
таймер Помодоро, поиск треков в iTunes, обложки альбомов
и популярные треки в Audius.

## Запуск

1. Откройте проект в VS Code.
2. Установите расширение Live Server (Ritwick Dey).
3. Правый клик по index.html → Open with Live Server.
4. Сайт откроется в браузере автоматически.

Перед запуском вставьте свой API-ключ Audius в main.js
(получить бесплатно: https://api.audius.co/plans).

## Источники API

1. iTunes Search API — https://performance-partners.apple.com/search-api
   - Без ключа, работает из России
   - Поиск треков и обложек альбомов

2. Audius JavaScript SDK — https://docs.audius.co/sdk/
   - Бесплатный ключ: https://api.audius.co/plans
   - Популярные треки

## Полезные промпты

1. Определение темы дашборда

   «Задание сделать дашборд. Нужно выбрать, на какую тему его сделать.
   Можешь провести мне опрос для определения темы?»

    Результат: Помог выбрать тему «Музыка», далее сузили до музыкального дашборда
   с API.

2. Выбор API, работающего в России

   «В дашборде нужно использовать API. Какую тему лучше выбрать
   и будет ли это работать в России?»

   Результат: Помог отсеять YouTube Music (блокировка DPI) и Spotify (закрытие API
   для РФ). Выбраны iTunes Search API и Audius SDK.

3. Сохранение и восстановление после перезагрузки

   «Добавь сохранение набора виджетов и задач в localStorage. После
   обновления восстанови классы из сохранённых данных, а API-запросы
   запусти заново. Повреждённый JSON и запрет сохранения не должны
   ломать панель».

    Результат: Помог реализовать сохранение виджетов, задач и состояния таймера
   между сессиями и защиту от повреждённого localStorage.
